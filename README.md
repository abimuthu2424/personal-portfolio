# Personal Portfolio Website

A responsive personal portfolio website built to showcase my skills, projects, education, and contact information.

## Features

* Responsive design for desktop and mobile devices
* Dark and light theme toggle
* Smooth navigation between sections
* Skills and technologies section
* Project showcase
* Education section
* Contact information
* Hover effects and responsive layouts

## Technologies Used

* HTML5
* CSS3
* JavaScript

## Project Structure

```text
personal-portfolio/
│
├── index.html
├── style.css
├── script.js
├── assets/
│   └── profile image
└── README.md
```

## How to Run

1. Clone this repository.
2. Open the project folder.
3. Open `index.html` in a web browser.

You can also use VS Code with the Live Server extension to run the website locally.

## Project Purpose

This project was developed to practice and demonstrate my frontend development skills using HTML, CSS, and JavaScript.
